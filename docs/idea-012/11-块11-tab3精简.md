## 要做的改动

### 1. 快捷按钮排只留两格

`BridgeQuickActions` 删掉后两行（终端 / BotMode / 权限 / 管理 四个按钮），只留 **截屏**、**点按**。
功能不丢：Manage 在设置页有入口（`SettingsScreen.kt:598`），Terminal / BotMode 在 Manage 页内可达
（`AppScaffold.kt:2120 / 2146`）。

### 2. 核心三项摊开到主屏（不折叠）

在「无人值守」和「Android 访问」两栏之间插一段常显区块，三项各一行，带状态勾 + 「测试」按钮（沿用现有那套）：

- **无障碍服务**（读屏 + 执行点按/输入）
- **屏幕捕获**（代理授权截图）
- **显示在其他应用上层**（悬浮窗）

这三项原本收在「Android 访问」汇总里，需要点开才看到。摊开之后，
`BridgeAndroidAccessSummaryCard` 里**只保留其余权限项**，不要重复展示这三项。

### 3. 第四项：设备和应用信息（`DEVICE_INFO`）直接可开关

同一区块里加第四行「设备和应用信息」，说明文案：给 Hermes 读取前台应用、读取 App 私有目录、取日志用。

- **直接给开关**，不跳二级页。走现成 API：
  `BridgeSafetyManager.setPermanentCapability(connectionId, BridgeCapability.DEVICE_INFO, allowed)`
  （`bridge/BridgeSafetyManager.kt:225`），`connectionId` 取当前连接，和 `BridgeSafetySettingsScreen.kt:522`
  那套能力开关用同一份数据，**不要另建一套存储**
- 行内显示当前授权状态（已允许 / 未允许）
- 主开关（Bridge master enabled）未开时置灰，并给一行提示「先开 Bridge 总开关」
- 授权变更后不要重启连接，现有能力读取每次都实时解析授权

### 4. 仪表台登录入口提到 tab3

原路径「设置 → 网关 → 第一个网关 → 访问 → 仪表台」，在 tab3 加一个直接入口。
**复用现有链路**（`NativeDashboardBrowserLauncher` + `DashboardSignInScreen` 那条），不要另写登录。
按钮文案沿用现有「仪表台」措辞；有登录态直接打开，没有就走登录页 —— 复用现有判断，不自己发明。
