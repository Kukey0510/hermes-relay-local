# 块15 · 脚本通道：拉取 / 缓存 / 回写

> 2026-11-13 立。前置：**块13 已完成**（tab2 的 tag 筛选 + 编辑 + 本地 DataStore 存储）。
> 本块只加「网络与同步」，不改块13 做好的 UI 结构。
> 接口契约：`docs/idea-012/13-scripts-api契约.md`（先读它，按里面的字段名写，别自己改名）。

## 目标

`assets/scripts.json` 那 4 条内置示例，换成「服务器可推、手机可拉、tag 改了能回写」的通道。

## 要做的改动

1. **本地缓存优先**
   - `ScriptCatalog` 现在的读取顺序改成：`filesDir/scripts/catalog.json` → 没有则 `assets/scripts.json`
   - 缓存文件结构 = 契约里的 `{"version": ..., "scripts": [...]}`
2. **拉取**（`GET {base}/scripts/catalog`，复用现有 Hermes API 基址 + bearer token）
   - 进入 tab2 自动拉一次，**5 分钟节流**（记录上次拉取时间，切 tab 来回不重复打）
   - tab2 顶部加一个刷新按钮，手动拉，无视节流
   - 成功：写缓存 → 刷新列表 → 顶部显示「同步于 xx:xx」
   - 失败：**保留旧缓存**，顶部显示「离线 · 上次同步 xx:xx」，列表照常展示，不许清空
3. **标签回写**（`POST {base}/scripts/tags`，整表覆盖）
   - 用户改完标签后立即提交全量 `{tags: {scriptId: [tag...]}}`
   - 提交失败：不回滚本地编辑，标「待同步」，下次拉取前先重试一次
4. **状态展示**
   - 拉取中 / 成功 / 离线 / 待同步 四种状态，一行文案即可，不要弹窗打断

## 不许碰
