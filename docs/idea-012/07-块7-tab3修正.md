# 块 7 · tab3 快捷入口修正（截图/点按 语义分开 + Play 版补齐）

先读 `00-总纲-云端版.md`（环境、硬约束、出包节奏）。基线：块1-6 已合并，tab3 已有 6 个快捷卡，tab2 已是脚本列表。

> 🔴 本块**不出包**（总纲 §6）：验收只认结构自检 + `assembleDebug` 编译通过。

---

## 1. 为什么要这一块（块5 验收时发现的两个问题）

1. **「截图 / 读屏」和「点按 / 手势」两张卡点下去是同一个动作**：`BridgeQuickActions` 里
   `onScreenshot = { openTimedSheet() }`、`onTap = { openTimedSheet() }`，两卡行为完全一致，
   文案承诺的能力和实际做的事对不上。
2. **两版不一致**：sideload 版（`BridgeScreen.kt`）有 6 个快捷卡，Google Play 版
   （`BridgeCoreScreen.kt`）只补了 Terminal / Bot Mode，没有截图、点按、权限入口。

## 2. 必须做

### A. 把两个入口的语义分开（只改入参，不改 sheet 组件本身）

1. 保留 `BridgeTimedAccessSheet` **不动**：不改签名、不改文案、不改视觉。
2. `openTimedSheet()` 增加一个「意图」入参（如 `openTimedSheet(intent: TimedSheetIntent)`，枚举
   `Screenshot` / `Tap` / `Neutral`）：
   - `Screenshot`：打开时 `inspectEnabled = true`、`controlEnabled = false`（只读 / 读屏）
   - `Tap`：打开时 `controlEnabled = true`、`inspectEnabled` 按现有默认（点按需要控制权）
   - `Neutral`：完全沿用现在 `openTimedSheet()` 的既有逻辑（现有 3 处调用点保持原行为）
   - 三个入口的初始勾选状态**只影响打开时的初始值**，用户仍可在 sheet 里自己改；点「允许」时提交的能力集合以 sheet 当前勾选为准，不要偷偷追加或裁掉能力。
3. `BridgeQuickActions` 里 `onScreenshot` / `onTap` 分别传对应 intent；卡片本身增加一行小字
   副标题说明区别（走 `strings.xml`），例如「只读屏幕内容」「模拟点击与手势」。

### B. Play 版补齐

4. `BridgeCoreScreen` 里补「截图/读屏」「点按/手势」「权限」三个入口（复用它的 `RelayNavTile`），
   testTag 与 sideload 版保持一致：`bridge.screenshot` / `bridge.tap` / `bridge.permissions`。
   - 若 `BridgeCoreScreen` 拿不到临时授权 sheet（它目前没有 safety 依赖），**不要为此新建一套权限逻辑**，
     改为调用从 `AppScaffold` 传进来的回调；回调为空时该入口不渲染。
5. 两版的快捷入口集合要能一眼对照：sideload = 截图 / 点按 / 终端 / Bot 模式 / 权限 / 管理；
   Play 版至少 = 截图 / 点按 / 终端 / Bot 模式 / 权限（管理入口按它现有导航保留）。

## 3. 明确不要做

- ❌ 不新增任何真实执行能力（不发截图、不点手机），本块只动入口与初始勾选
- ❌ 不改 `BridgeTimedAccessSheet` 的签名/文案/视觉
- ❌ 不改任何现有 route 字符串；不新增 route
- ❌ 不改 `BridgeViewModel` / 安全策略内部逻辑
- ❌ 不动 tab1 / tab2 / tab4
- ❌ 不加第三方依赖

## 4. 验收（必须给证据）

1. `./gradlew assembleDebug` 通过，贴最后 15 行（两个 flavor 都要过）。
2. 逐条写清：
   - 点「截图/读屏」打开 sheet 时，初始勾选是什么（读屏开 / 控制关？按你的实现如实写）
   - 点「点按/手势」打开 sheet 时，初始勾选是什么
   - 现有另外几处打开同一个 sheet 的入口，初始勾选与改动前一致（列出调用点）
   - Play 版三个入口在拿不到回调时的表现（不渲染，而不是崩）
3. 交付说明：改动文件、新增 strings key、新增 testTag、两版入口对照表。
